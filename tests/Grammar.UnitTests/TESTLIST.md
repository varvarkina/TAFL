# Список тестов валидатора грамматики выражений

## Валидные выражения (должны проходить ValidateText)

### Числовые литералы
- Целое число: `2025` => valid
- Вещественное число: `3.14` => valid
- Ноль: `0` => valid
- Дробное число: `123.456` => valid

### Унарные операторы
- Унарный минус (целое): `-5` => valid
- Унарный минус (вещественное): `-3.14` => valid
- Унарный плюс: `+5` => valid
- Унарный плюс: `+42` => valid
- Логическое НЕ: `!1` => valid
- Логическое НЕ: `!0` => valid

### Возведение в степень (^)
- Простая степень: `2 ^ 3` => valid
- Правая ассоциативность: `2 ^ 3 ^ 2` => valid
- Отрицательное основание в скобках: `(-2) ^ 3` => valid
- Дробная степень: `4 ^ 0.5` => valid

### Мультипликативные операторы (* / // %)
- Умножение: `2 * 3` => valid
- Деление: `6 / 2` => valid
- Целочисленное деление: `7 // 2` => valid
- Остаток: `7 % 3` => valid

### Деление на ноль (синтаксически валидно)
- Деление на ноль: `5 / 0` => valid
- Целочисленное деление на ноль: `5 // 0` => valid
- Остаток от деления на ноль: `5 % 0` => valid

### Аддитивные операторы (+ -)
- Сложение: `1 + 2` => valid
- Вычитание: `5 - 3` => valid

### Операторы сравнения (< > <= >=)
- Меньше: `3 < 5` => valid
- Меньше: `5 < 5` => valid
- Меньше: `6 < 5` => valid
- Больше: `3 > 5` => valid
- Больше: `5 > 5` => valid
- Больше: `6 > 5` => valid
- Меньше или равно: `3 <= 5` => valid
- Меньше или равно: `5 <= 5` => valid
- Меньше или равно: `6 <= 5` => valid
- Больше или равно: `3 >= 5` => valid
- Больше или равно: `5 >= 5` => valid
- Больше или равно: `6 >= 5` => valid

### Равенство/неравенство (== !=)
- Равенство: `5 == 5` => valid
- Равенство: `5 == 3` => valid
- Неравенство: `5 != 3` => valid
- Неравенство: `5 != 5` => valid

### Логические операторы (&& ||)
- Логическое И: `1 && 1` => valid
- Логическое И: `1 && 0` => valid
- Логическое И: `0 && 1` => valid
- Логическое И: `0 && 0` => valid
- Логическое ИЛИ: `1 || 1` => valid
- Логическое ИЛИ: `1 || 0` => valid
- Логическое ИЛИ: `0 || 1` => valid
- Логическое ИЛИ: `0 || 0` => valid

### Приоритет и ассоциативность
- Левая ассоциативность (-): `10 - 3 - 2` => valid
- Левая ассоциативность (/): `12 / 3 / 2` => valid
- Унарный и аддитивный: `-3 + 2` => valid
- Степень и умножение: `2 ^ 3 * 2` => valid
- Умножение и степень: `2 * 3 ^ 2` => valid
- Сложение и умножение: `2 + 3 * 4` => valid
- Сложение и умножение: `3 + 2 * 3` => valid
- Аддитивный и сравнение: `1 + 2 > 2` => valid
- Сравнение и равенство: `1 < 2 == 5 > 4` => valid

### Скобки
- Скобки меняют приоритет: `(1 + 2) * 3` => valid
- Скобки в правом операнде: `2 * (3 + 4)` => valid
- Вложенные скобки: `((1 + 2) * 3) + 4` => valid

### Встроенные функции
- `abs` с целым: `abs(-5)` => valid
- `abs` с целым: `abs(5)` => valid
- `abs` с вещественным: `abs(-3.14)` => valid
- `min` (3 аргумента): `min(7, 3, 5)` => valid
- `min` (1 аргумент): `min(1)` => valid
- `min` (2 аргумента): `min(5, 2)` => valid
- `max` (3 аргумента): `max(2, 8, 4)` => valid
- `max` (1 аргумент): `max(1)` => valid
- `max` (2 аргумента): `max(5, 2)` => valid

### Комбинированные выражения
- Функция + число: `abs(-5) + 3` => valid
- Функция * число: `min(10, 20) * 2` => valid
- Функция ^ число: `max(1, 2, 3) ^ 2` => valid
- Скобки + функция: `(1 + 2) * abs(-3)` => valid

### Вызовы функций с пустыми аргументами
- Пустой `abs`: `abs()` => valid
- Пустой `min`: `min()` => valid
- Пустой `max`: `max()` => valid

## Невалидные выражения (должны падать ValidateText)

### Строковые литералы (не поддерживаются грамматикой)
- Строка: `"hello"` => invalid
- Пустая строка: `""` => invalid
- Конкатенация строк: `"hello" + "world"` => invalid
- Конкатенация с пустой: `"test" + ""` => invalid
- Равенство строк: `"hello" == "hello"` => invalid
- Равенство строк: `"hello" == "world"` => invalid
- Неравенство строк: `"hello" != "world"` => invalid
- Число + строка: `1 + "hello"` => invalid
- Строка - число: `"world" - 5` => invalid
- Строка * число: `"test" * 2` => invalid
- Строка / число: `"abc" / 3` => invalid

### Пустой ввод
- Пустая строка: `` => invalid
- Только пробелы: `   ` => invalid

### Битые числовые литералы
- Две точки: `1..2` => invalid
- Несколько точек: `1.2.3` => invalid
- Один символ точки: `.` => invalid
- Две точки: `..` => invalid
- Точка без дробной части: `1.` => invalid
- Дробь без целой части: `.5` => invalid

### Унарные (нет операнда / некорректные цепочки)
- Только минус: `-` => invalid
- Только плюс: `+` => invalid
- Только !: `!` => invalid
- Двойное ! без операнда: `!!` => invalid
- ! перед бинарным +: `! + 1` => invalid
- - перед *: `- * 2` => invalid
- + перед /: `+ / 2` => invalid

### Возведение в степень (^)
- Оператор без левого операнда: `^ 2` => invalid
- Оператор без правого операнда: `2 ^` => invalid
- Два оператора подряд: `2 ^ ^ 3` => invalid
- Незакрытая скобка: `(2 ^ 3` => invalid
- Лишняя закрывающая скобка: `2 ^ 3)` => invalid

### Мультипликативные (* / // %)
- * без левого: `* 2` => invalid
- * без правого: `2 *` => invalid
- / без левого: `/ 2` => invalid
- / без правого: `2 /` => invalid
- // без левого: `// 2` => invalid
- // без правого: `2 //` => invalid
- % без левого: `% 2` => invalid
- % без правого: `2 %` => invalid
- Два оператора: `2 * / 3` => invalid
- Два оператора: `2 / * 3` => invalid
- Два оператора: `2 % % 3` => invalid

### Аддитивные (+ -)
- Унарный плюс в отдельном виде: `+ 1` => invalid
- + без правого: `1 +` => invalid
- Унарный минус с пробелом: `- 1` => invalid
- - без правого: `1 -` => invalid
- Два плюса: `1 + + 2` => invalid
- Минус и минус без операнда: `1 - -` => invalid
- + и *: `1 + * 2` => invalid
- - и /: `1 - / 2` => invalid

### Сравнения (< > <= >=)
- < без правого: `1 <` => invalid
- < без левого: `< 1` => invalid
- > без правого: `1 >` => invalid
- > без левого: `> 1` => invalid
- <= без правого: `1 <= ` => invalid
- >= без левого: `>= 1` => invalid
- Двойной <: `1 < < 2` => invalid
- Двойной >=: `1 >= >= 2` => invalid

### Равенство/неравенство (== !=)
- == без правого: `1 ==` => invalid
- == без левого: `== 1` => invalid
- != без правого: `1 !=` => invalid
- != без левого: `!= 1` => invalid
- Двойной ==: `1 == == 2` => invalid
- Двойной !=: `1 != != 2` => invalid

### Логические (&& ||)
- && без правого: `1 &&` => invalid
- && без левого: `&& 1` => invalid
- || без правого: `1 ||` => invalid
- || без левого: `|| 1` => invalid
- Двойной &&: `1 && && 0` => invalid
- Двойной ||: `1 || || 0` => invalid
- Смешанные без операнда: `1 && || 0` => invalid

### Скобки
- Открывающая без содержимого: `(` => invalid
- Закрывающая без открывающей: `)` => invalid
- Пустые скобки: `()` => invalid
- Незакрытая: `(1 + 2` => invalid
- Лишняя закрывающая: `1 + 2)` => invalid
- Незакрытая вложенная: `((1 + 2) * 3` => invalid
- Лишняя закрывающая: `(1 + 2))` => invalid
- Обратный порядок: `)(1)` => invalid

### Лишние токены (нет оператора между операндами)
- Два числа подряд: `1 2` => invalid
- Две группы подряд: `(1) (2)` => invalid
- Вызов функции и число подряд: `abs(1) 2` => invalid

### Вызовы функций (ошибки списка аргументов)
- `abs(`: `abs(` => invalid
- `abs)` (закрывающая без открывающей): `abs)` => invalid
- `abs(1` (нет закрывающей): `abs(1` => invalid
- `abs(,)`: `abs(,)` => invalid
- `abs(,1)`: `abs(,1)` => invalid
- `abs(1,)`: `abs(1,)` => invalid
- `min(`: `min(` => invalid
- `min(1`: `min(1` => invalid
- `min(1, )`: `min(1, )` => invalid
- `min(, 1)`: `min(, 1)` => invalid
- `min(1,,2)`: `min(1,,2)` => invalid
- `min(1,2,)`: `min(1,2,)` => invalid
- `min(,)`: `min(,)` => invalid
- `max(`: `max(` => invalid
- `max(1`: `max(1` => invalid
- `max(1, )`: `max(1, )` => invalid
- `max(, 1)`: `max(, 1)` => invalid
- `max(1,,2)`: `max(1,,2)` => invalid
- `max(1,2,)`: `max(1,2,)` => invalid
- `max(,)`: `max(,)` => invalid

### Ошибки внутри аргументов функций
- Ломаные скобки в аргументах: `min((1,2)` => invalid
- Ломаное выражение в аргументе: `max(1 +, 2)` => invalid
- Ломаное выражение в аргументе: `abs(1 + )` => invalid
