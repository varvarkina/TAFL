# Список тестов для лексера DEA

## 1. Ключевые слова (Keywords)
- [ ] Распознавание ключевого слова `var` (нижний регистр).
- [ ] Распознавание ключевого слова `const`.
- [ ] Распознавание ключевого слова `func`.
- [ ] Распознавание ключевого слова `proc`.
- [ ] Распознавание ключевого слова `return`.
- [ ] Распознавание ключевого слова `if`.
- [ ] Распознавание ключевого слова `else`.
- [ ] Распознавание ключевого слова `while`.
- [ ] Распознавание ключевого слова `for`.
- [ ] Распознавание ключевого слова `to`.
- [ ] Распознавание ключевого слова `downto`.
- [ ] Распознавание ключевого слова `break`.
- [ ] Распознавание ключевого слова `continue`.
- [ ] Распознавание ключевого слова `true`.
- [ ] Распознавание ключевого слова `false`.
- [ ] Распознавание ключевого слова `input`.
- [ ] Распознавание ключевого слова `print`.
- [ ] Регистронезависимость ключевых слов (например, `VAR`, `Var`, `var` — один и тот же токен).

## 2. Идентификаторы (Identifiers)
- [ ] Распознавание идентификатора, начинающегося с буквы.
- [ ] Распознавание идентификатора, содержащего цифры (но не в начале).
- [ ] Идентификатор не должен совпадать с ключевыми словами.
- [ ] Регистрозависимость идентификаторов (`myVar` != `myvar`).

## 3. Литералы (Literals)
### 3.1. Числа
- [ ] Целое число (0, 123).
- [ ] Ведущий ноль разрешен только для числа 0.
- [ ] Десятичная дробь (1.23).
- [ ] Дробь с нулем в начале (0.5).

### 3.2. Строки
- [ ] Однострочный строковый литерал в двойных кавычках `"text"`.
- [ ] Пустая строка `""`.
- [ ] Escape-последовательность `\"` (двойная кавычка).
- [ ] Escape-последовательность `\\` (обратный слэш).
- [ ] Escape-последовательность `\n` (перевод строки).
- [ ] Escape-последовательность `\t` (табуляция).
- [ ] Escape-последовательность `\r` (возврат каретки).
- [ ] Ошибка при незакрытой кавычке.

## 4. Операторы (Operators)
- [ ] Присваивание `=`.
- [ ] Неравенство `!=`.
- [ ] Равенство `==`.
- [ ] Меньше или равно `<=`.
- [ ] Больше или равно `>=`.
- [ ] Меньше `<`.
- [ ] Больше `>`.
- [ ] Умножение `*`.
- [ ] Деление `/`.
- [ ] Целочисленное деление `//`.
- [ ] Остаток от деления `%`.
- [ ] Вычитание/Унарный минус `-`.
- [ ] Сложение `+`.
- [ ] Логическое И `&&`.
- [ ] Логическое ИЛИ `||`.
- [ ] Логическое НЕ `!`.

## 5. Прочие лексемы (Delimiters)
- [ ] Разделитель `;`.
- [ ] Разделитель `,`.
- [ ] Разделитель `:`.
- [ ] Скобки `(` и `)`.
- [ ] Блок кода `{` и `}`.

## 6. Комментарии (Comments)
- [ ] Однострочный комментарий `#`.
- [ ] Многострочный комментарий `/* ... */`.
- [ ] Игнорирование комментариев лексером.

## 7. Комплексные тесты
- [ ] Последовательность токенов: `var x: int = 10;`.
- [ ] Блок кода с отступами и переносами строк.
