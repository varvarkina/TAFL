# Различия **Pascal** и **C++** в их лексической структуре

## 1. Элементы структурного программирования (блоки кода, ветвления, циклы)

## 1.1 Блоки кода
- ### Pascal
    - `begin`/`end` - парные ключевые слова
    - Разделитель: `;` 
    - Обязательные точки с запятой между операторами.
    - Точка с запятой перед ключевым словом `end` не ставится, потому что слово `end` является закрывающей операторной скобкой и одновременно указывает конец предыдущего оператора. 
    - Пробелы и переносы строк в Pascal не значимы, лексемы разделяются пробелами или символами управления.
    ```
    begin
        statement1;
        statement2
    end;
    ```

- ### C++
    - Использование символов вместо ключевых слов для блоков
    - Разделители: `{`, `}`, `;`
    - Директивы препроцессора (например, `#include`) не требуют точки с запятой
    - Переносы строк и пробелы важны только в макросах (`#define`) — там лексический анализ ведётся на другом уровне (препроцессорном).
    ```
    {
        statement1;
        statement2;
    }
    ```

## 1.2 Ветвления
## Условные операторы
- ### Pascal
    ```
    if condition then
        statement1
    else
        statement2;
    ```

- ### C++
    ```
    if (condition) {
        statement1;
    } else {
        statement2;
    }
    ```

- ### Ключевые различия для лексического анализатора:

    | Аспект | Pascal | C++ |
    |--------|---------|-----|
    | **Условие в скобках** | Нет | Обязательно `(condition)` |
    | **Ключевое слово THEN** | Обязательно | Отсутствует |

## Операторы ветвления case/switch
- ### Pascal
    ```
    case expr of 
        val1: stmt1;
        val2: stmt2;
    end;
    ```
    - Каждое значение expr сравнивается с константами
    - Метки case - только простые константы
    - Выполняется не более одного оператора
    - В классическом Pascal нет встроенного default (ветки else)
- ### C++
    ```
    switch(expr) {
        case val1: stmt1; break;
        case val2: stmt2; break;
        default: stmtDefault; break;
    }
    ```
    - Значение в switch помещается в скобки
    - Метки case - константные выражения времени компиляции
    - Если break не указать, может быть выполнено несколько операторов case.
    - По умолчанию выполняется default. 
  
## 1.3 Циклы
- ### Pascal - три типа циклов

    #### WHILE-DO
    ```pascal
    while condition do
        statement;
    ```

    #### REPEAT-UNTIL
    ```pascal
    repeat
        statement1;
        statement2;
    until condition;
    ```

    #### FOR
    ```pascal
    for i := 1 to 10 do
        statement;

    for i := 10 downto 1 do
        statement;
    ```

- ### C++ - три типа циклов

    #### WHILE
    ```cpp
    while (condition) {
        statement;
    }
    ```

    #### DO-WHILE
    ```cpp
    do {
        statement;
    } while (condition);
    ```

    #### FOR
    ```cpp
    for (int i = 1; i <= 10; i++) {
        statement;
    }
    ```

| Аспект | Pascal | C++ |
|--------|---------|-----|
| **FOR переменная** | Объявляется отдельно | Объявляется в заголовке |
| **FOR направление** | `to`/`downto` | Управляется условием |
| **FOR шаг** | Всегда 1 | Любой (`i++`, `i+=2`, etc) |
| **FOR безопасность** | Выше (FOR защищён) | Ниже (полная свобода) |
| **Цикл с постусловием** | `repeat-until` (пока ложно) | `do-while` (пока истинно) |
| **Блоки тела** | `begin..end` для нескольких операторов | `{}` всегда |

## 2. Средства ввода/вывода и встроенные функции

- ### Pascal - процедурный подход:
  
  - **Ключевые слова IO**: `read`, `readln`, `write`, `writeln`
  - **Процедуры являются частью языка и не требуют дополнительных библиотек**
  - **Поддержка форматирования вывода**: `value:width:precision`  - минимальная общая ширина : количество знаков после запятой
  - **Встроенные функции**: `sin`, `cos`, `sqrt` - Математические; `length`, `copy` - Строковые
  - **Операторы**: `:=`, `:`
      ```
      read(x);                    // Чтение одного значения
      writeln('Result: ', x:0:2); // Форматированный вывод (0 = автоопределение общей ширины)
      x := sin(y);                // Синус
      len := length(str);         // Длина строки
      ```

- ### C++ - потоковый подход:
  - **Идентификаторы IO**: `cin`, `cout`, `endl`, `getline`, `fixed`, `setprecision`
  - **Ввод и вывод реализуются через объекты потоков библиотеки `<iostream>`**:
      - `std::cin` — для ввода,
      - `std::cout` — для вывода.
  - **Для удобства часто используют** `using namespace std;`
  - **Можно использовать функции из языка С** (`<cstdio>`): `scanf`, `printf` и т.д.
  - **Форматированный вывод**: `cout << "Number: " << setw(10) << setprecision(2) << x;` через библиотеку <iomanip>
  - **Библиотечные функции**: `sin`, `cos`, `sqrt` - Математические; `length`, `substr` - Строковые (методы класса)
  - **Операторы потоков**: `>>`, `<<`
  - **Операторы методов**: `.`
      ```
      cin >> a >> b >> c; // Чтение нескольких значений
      getline(cin, str);  // Чтение строки
      cout << "Result: " << x << endl; // Вывод с переводом строки
      cout << fixed << setprecision(2) << x; // Форматированный вывод
      x = sin(y);         // Синус
      len = str.length();         // Длина строки
      ```

## 3. Пользовательские функции, включая параметры и возвращаемые значения

- ### Pascal - разделение на функции и процедуры

    #### Функция (возвращает значение):
    ```pascal
    function Add(a, b: integer): integer;
    begin
        Add := a + b;
    end;
    ```
    - Ключевые слова: `function`, `begin`, `end`
    - Разделители: `:`, `;`, `(`, `)`, `,`
    - Оператор присваивания возврата: `:=`

    #### Процедура (не возвращает значение):
    ```pascal
    procedure PrintResult(value: integer);
    begin
        writeln('Result: ', value);
    end;
    ```
    - Ключевые слова: `procedure`, `begin`, `end`

- ### C++ - единый синтаксис функций

    #### Функция:
    ```cpp
    int add(int a, int b) {
        return a + b;
    }
    ```
    - Ключевые слова: `return`
    - Разделители: `{`, `}`, `(`, `)`, `,`, `;`
    - Оператор возврата: `return`

    #### Void функция (аналог процедуры):
    ```cpp
    void printResult(int value) {
        cout << "Result: " << value << endl;
    }
    ```

## Параметры функций

- ### Pascal
```pascal
procedure Process(x: integer; var y: integer; const z: real);
```
- `var`, `const` - это ключевые слова на лексическом уровне, которые компилятор распознаёт как отдельные сущности при разборе параметров.
- Разделитель параметров: `;`
- Явное указание типа после `:`

- ### C++
```cpp
void process(int x, int& y, const double z);
```
- `&`, `const` - это часть системы типов, которые компилятор интерпретирует в контексте объявления типа, а не как независимые модификаторы параметров.
- Разделитель параметров: `,`
- Тип перед идентификатором

## 4. Встроенные типы данных для целых чисел, чисел с плавающей точкой и строк

- ### Целые типы

  * **Pascal:** `Integer`, `ShortInt`, `LongInt` и др. (обычно 16–32 бита).
  
    Поддерживаются литералы:

    | Тип литерала | Синтаксис | Пример | Результат | Поддержка |
    |--------------|-----------|---------|------------|-----------|
    | **Десятичный** | `[знак]цифры` | `123`, `-456` | 123, -456 | Все версии |
    | **С разделителем** | `цифры_цифры` | `1_000_000` | 1000000 | Современные диалекты |
    | **Шестнадцатеричный** | `$hex` | `$FF`, `$1A3F` | 255, 6719 | Все версии |
    | **Двоичный** | `%binary` | `%1101`, `%1010_1101` | 13, 173 | Современные диалекты |
    | **Восьмеричный** | `&octal` | `&77`, `&123` | 63, 83 | Некоторые диалекты |
  
    **Булев тип** — `Boolean`
      - литералы `true` и `false`
      - Преобразование в int явное:	`Ord(False)=0`, `Ord(True)=1`
      - Преобразование из int	Явное: `Boolean(x)`
  
  * **C++:** `int`, `short`, `long`, `long long`, `unsigned` (обычно 32–64 бита).
    
    Литералы:
  
    | Тип литерала | Синтаксис | Пример | Результат | Стандарт |
    |--------------|-----------|---------|------------|----------|
    | **Десятичный** | `[знак]цифры[суффикс]` | `123`, `-456` | 123, -456 | C++98 |
    | **С разделителем** | `цифры'цифры` | `1'000'000` | 1000000 | C++14 |
    | **Шестнадцатеричный** | `0xhex[суффикс]` | `0xFF`, `0x1A3FU` | 255, 6719u | C++98 |
    | **Двоичный** | `0bbinary[суффикс]` | `0b1101`, `0b1010'1101` | 13, 173 | C++14 |
    | **Восьмеричный** | `0octal[суффикс]` | `077`, `0123L` | 63, 83L | C++98 |
  
    **Булев тип** — `bool`
      - литералы `true` и `false`
      - Преобразование в int неявное: false=0, true=1
      - Преобразование из int	Неявное: 0→false, остальное→true

- ### Вещественные типы

    * **Pascal:** 
      ```
      var
        r: Real;        { Основной вещественный тип, обычно 6 байт }
        s: Single;      { Одинарная точность, 4 байта }
        d: Double;      { Двойная точность, 8 байт }
        e: Extended;    { Расширенная точность, 10 байт }
        c: Comp;        { Целочисленный тип с плавающей точкой, 8 байт }
      ```
    * **C++:** 
      ```
      float f;           // Одинарная точность, 4 байта
      double d;          // Двойная точность, 8 байт
      long double ld;    // Расширенная точность, обычно 10-16 байт
      ```

- ### Символы и строки

  * **Pascal:** 
    - символы (тип `Char`) и строки в одинарных кавычках (`'A'`, `'Hello'`)
    - тип `String` — статической (`String[100]`) или динамической длины `s2: String;`(до 255 символов в классическом Pascal).
    - `'Don''t forget' { Экранирование апострофа }`
  
  * **C++:** 
    - символы `char` в `' '`
    - строки в `" "`. Используется:
      -  `std::string` — объекты библиотеки STL
      -  C-строки (массивы символов):
      ```
      char str1[100] = "Hello";           // Массив фиксированного размера
      char str2[] = "World";              // Массив с автоматическим размером
      const char* str3 = "Constant";      // Указатель на строковый литерал
      ```
      - `"Line 1\nLine 2"        // С escape-последовательностями`

## 5. Выражения и операторы

## 5.1 Арифметические операторы

* **Pascal**

  * Набор: `+`, `-`, `*`, `/`, `div`, `mod`.
  * `/` — всегда вещественное деление; целочисленное — `div`. Остаток — `mod`.
  * Нет инкремента/декремента `++/--` (обычно используются `inc`, `dec`).
  * `div/mod` — **ключевые слова**, поэтому токены для них — отдельные лексемы (`DIV`, `MOD`).
  * Пример: `x := (a div b) + c;`
* **C++**

  * Набор: `+`, `-`, `*`, `/`, `%`, `++`, `--`.
  * Деление `/` — поведение зависит от типов операндов (целое/вещественное).
  * `%` — только для целых.
  * `*` может быть также токеном объявления указателя — лексическая неоднозначность разрешается контекстом.
  * Пример: `x = (a / b) + c;`

## 5.2 Логические операторы

* **Pascal**
  * Операторы: `and`, `or`, `not` (встроенные ключевые слова).
  * Пример: `if (a > 0) and (b > 0) then ...`
* **C++**
  * Операторы: `&&`, `||`, `!` — **символьные токены**.
  * Пример: `if (a > 0 && b > 0) { ... }`

## 5.3 Операторы сравнения

* **Pascal:** `=`, `<>`, `<`, `>`, `<=`, `>=`. 
  Пример: `if a <> b then ...`
* **C++:** `==`, `!=`, `<`, `>`, `<=`, `>=`. 
  Пример: `if (a != b) ...`

## 6. Пользовательские составные типы

## 6.1. Массивы

* **Pascal**

  * Синтаксис объявления: `array [L..U] of T`.

    * **Произвольные диапазоны** индексов (например `array[-5..5] of Integer` или `array[1..10]`).
    * Диапазон (`..`) — отдельный лексический токен (`RANGE`), L и U — константные выражения/типические значения.
  * Семантика: компилятор **знает границы** массива в типе → возможно статическое выделение, генерация проверок выхода за границы (runtime bounds checks) при желании/опции.
  * Передача в процедуры: в классическом Pascal при передаче массива параметром поведение зависит от уровня языка; обычно передаётся копия или указатель (диалектно).
  * Пример: `var a: array[1..10] of Integer;`
* **C++**

  * Статический массив: `T a[N];` — индекс от `0` до `N-1`.
  * STL/динамические: `std::vector<T> v;` — динамический размер, методы `.at(i)` (с проверкой) и `operator[]` (без проверки).
  * При передаче в функцию массив «деградирует» до указателя (`T a[]` → `T* a`) — информация о размере теряется; это важно семантически.
  * Пример: `int a[10];` или `std::vector<int> v; v.push_back(1);`

## 6.2 Структуры / записи

* **Pascal (`record`)**

  * Синтаксис:

    ```pascal
    type
      TPoint = record
        x, y: Integer;
      end;
    ```
  * Поля перечисляются списками имён перед двоеточием: `x, y: Integer;`.
  * **Нет методов** в классическом стандарте (Object Pascal/Delphi добавляет методы/конструкторы).

* **C++ (`struct` / `class`)**

  * Синтаксис:

    ```cpp
    struct Point {
        int x;
        int y;
    };
    ```
  * Может содержать **методы**, **конструкторы**, **деструкторы**, **спецификаторы доступа** (`public`, `private`, `protected`), **наследование**, виртуальные функции.
  * Инициализация: списки инициализации, конструкторы, Агрегатная инициализация: `int arr {1, 2, 3};`.
