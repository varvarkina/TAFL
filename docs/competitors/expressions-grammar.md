# Различия Pascal и C++ в синтаксисе выражений

## 1. Сравнение числовых типов данных

* **Pascal**

  * Типовая система: `integer`, `shortint`, `longint`, `cardinal` и т. п.; вещественные: `real`, `single`, `double`, `extended` (зависит от реализации).
  * Объявление: постфиксно: `var x: integer;`
  * Семантика деления: `/` — вещественное деление; целочисленное деление — ключевое слово `div`; остаток — `mod`.
  * Присваивание: `:=` (не выражение - нельзя вкладывать присваивания внутрь других выражений).

* **C++**

  * Типовая система: `int`, `short`, `long`, `long long`, `unsigned ...`, `float`, `double`, `long double`.
  * Объявление: префиксно: `int x; double y;`
  * Семантика деления: `/` — если оба операнда целые → целочисленное деление; иначе → вещественное; остаток `%` — для целых типов.
  * Присваивание: `=` — выражение (возвращает значение), правоассоциативно.

---

## 2. Сравнение арифметических операторов

* **Pascal**

  * Операторы: `+`, `-`, `*`, `/` (вещественное деление), `div` (целочисленное деление), `mod` (остаток).
  * Унарные `+`/`-`.
  * Нет встроенного `**` (степень) — функция `sqr`/`power` используется.

* **C++**

  * Операторы: `+`, `-`, `*`, `/`, `%` (остаток — для целых), `<<` `>>` (сдвиги), префикс/постфикс `++/--`.
  * Унарные `+`/`-`.
  * Степень — библиотечная функция `std::pow`.

---

## 3. Сравнение приоритетов операций

* **Pascal** 

  1. Унарные: `+` `-` `not`
  2. Мультипликативные: `*` `/` `div` `mod`
  3. Аддитивные: `+` `-`
  4. Операции сравнения: `=` `<>` `<` `<=` `>` `>=`
  5. Логические: `and`, `or`, `xor`
  6. Присваивание `:=` — не выражение (на уровне statement)

* **C++**

  1. Постфиксные: `()`, `[]`, `.`, `->`, `++/--` (постфикс)
  2. Унарные: `++/--`, `+/-`, `!`, `~`, `&`, `*`
  3. Мультипликативные: `*` `/` `%`
  4. Аддитивные: `+` `-`
  5. Сдвиги: `<<` `>>`
  6. Сравнения: `<` `<=` `>` `>=`
  7. Равенство: `==` `!=`
  8. Побитовые: `&` `^` `|`
  9. Логические: `&&` `||`
  10. Условный `?:`
  11. Присваивания (правоассоциативны) `=`, `+=`, ...
  12. Запятая `,` — самый низкий приоритет

---

## 4. Список лево- и правоассоциативных операторов

* **Pascal**

  * **Левоассоциативны (бинарные):** `*`, `/`, `div`, `mod` ; `+`, `-` ; `and`, `or`, `xor`
  * **Правоассоциативных бинарных операторов в выражениях нет.**
  * **Примечание:** оператор присваивания `:=` — не выражение (он не входит в дерево выражений и потому ассоциативность к нему не применяется).

* **C++**

  * **Левоассоциативны (бинарные):** `*`, `/`, `%` ; `+`, `-` ; `<<`, `>>` ; `<`, `<=`, `>`, `>=` ; `==`, `!=` ; `&`, `^`, `|` ; `&&` ; `||` ; `,`
  * **Правоассоциативны (бинарные):** присваивания (`=`, `+=`, `-=`, `*=`, `/=`, `%=` и т.д.), тернарный оператор `?:`
  * **Примечание:** унарные операторы (префиксные `+`, `-`, `!`, `~`, `++`, `--` и др.) и постфиксные операции (`x++`, `x--`, вызов `()`, индексация `[]`, доступ `.`/`->`) не рассматриваются как «ассоциативные» бинарные операции — они имеют собственный (высокий) приоритет и особую семантику, поэтому в таблицах ассоциативности обычно не перечисляются.

---

## 5. Сравнение встроенных функций для работы с числами

| Операция      | Pascal (стандарт/диалект)                     | C++ (стандартная библиотека)            |
| ------------- | --------------------------------------------- | --------------------------------------- |
| Модуль        | `abs(x)` (для целых), `abs`/`fabs` (диалекты) | `std::abs`, `std::fabs` (`<cmath>`)     |
| Корень        | `sqrt(x)`                                     | `std::sqrt` (`<cmath>`)                 |
| Степень       | `sqr(x)` или библиотечные `power`             | `std::pow` (`<cmath>`)                  |
| Округление    | `round`, `trunc` (диалекты)                   | `std::round`, `std::floor`, `std::ceil` |
| Логарифм      | `ln`, `log10` (диалекты)                      | `std::log`, `std::log10`                |
| Тригонометрия | `sin`, `cos`, `tan`                           | `std::sin`, `std::cos`, `std::tan`      |
| Случайные     | `random` / `randomize` (диалекты)             | `<random>` / `std::rand`                |
