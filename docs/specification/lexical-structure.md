# Лексическая структура языка DEA

## 1. Примеры кода

### Блоки кода

```dea
{
    print("Hello!");
}
```

### Ветвление `if-else`

```dea
var age: int;
print("Enter age: ");
input(age);

if (age >= 18) 
{
    print("Access granted.");
} 
else 
{
    print("Access denied.");
}
```

### Циклы

```dea
var i: int;
i = 1;

while (i <= 5) 
{
    print(i);
    print(" ");
    i = i + 1;
}
```

```dea
var i: int;

for i := 1 to 10 
{
    print(i);
}
```

```dea
for i := 10 downto 1 
{
    print(i);
}
```

### Функции

```dea
func add(a: int, b: int): int {
    return a + b;
}

proc printResult(value: int) {
    print("Result: ", value);
}
```

## 2. Ключевые слова

| Слово                      | Предназначение                                    |
| -------------------------- | ------------------------------------------------- |
| **var**                    | Объявление переменной                             |
| **const**                  | Объявление константы                              |
| **func**                   | Объявление функции, возвращающей значение         |
| **proc**                   | Объявление процедуры (без возвращаемого значения) |
| **return**                 | Возврат значения                                  |
| **if**                     | Начало условного ветвления                        |
| **else**                   | Альтернативная ветка условия                      |
| **while**                  | Цикл с предусловием                               |
| **for**                    | Цикл с параметром                                 |
| **to**                     | Рост индекса цикла `for`                          |
| **downto**                 | Убывание индекса цикла `for`                      |
| **break**                  | Досрочный выход из цикла                          |
| **continue**               | Пропустить итерацию и перейти к следующей         |
| **true**                   | Булев литерал: истина                             |
| **false**                  | Булев литерал: ложь                               |
| **input**                  | Ввод значения                                     |
| **print**                  | Вывод текста/значения без перевода строки         |

В DEA ключевые слова регистронезависимые. Например, это всё варианты одного и того же ключевого слова: "const", "CONST", "ConSt".

## 3. Идентификаторы

Идентификатор может:
- Начинаться с буквы латинского алфавита (A-Z, a-z)
- Содержать:
  - буквы (как указано выше),
  - арабские цифры 0, 1, ..., 9

Ограничения:
- Идентификатор не должен совпадать с ключевыми словами языка
- Минимальная длина — 1 символ, максимальная не ограничена
- Регистр имеет значение (myVar != myvar)  

## 4. Литералы

### 4.1. Литералы чисел

Допускаются следующие литералы чисел:

- Литерал целого числа:
  - Состоит из арабских цифр 0, 1, ..., 9
  - Ведущий 0 разрешён только если число равно нулю
  - Поддерживается одна система счисления — десятичная
- Литерал десятичной дроби:
  - Состоит из арабских цифр 0, 1, ..., 9 и одного разделителя "." в середине литерала

### 4.2. Литералы строк

Однострочный строковый литерал обрамляется двойными кавычками `" "`.

Без экранирования внутри строки нельзя использовать:

- символ новой строки
- двойные кавычки `"`
- обратный слэш \, если он не используется для escape-последовательности

Поддерживаются escape-последовательности:

| Escape | Значение          |
| ------ | ----------------- |
| `\"`   | Двойные кавычки   |
| `\\`   | Обратный слэш     |
| `\n`   | Перевод строки    |
| `\t`   | Табуляция         |
| `\r`   | Возврат каретки   |

## 5. Операторы

| Оператор | Предназначение                   |
| -------: | -------------------------------- |
|      `=` | присваивание                     |
|     `!=` | неравенство                      |
|     `==` | равенство                        |
|     `<=` | меньше или равно                 |
|     `>=` | больше или равно                 |
|      `<` | меньше                           |
|      `>` | больше                           |
|      `*` | умножение                        |
|      `/` | деление                          |
|     `//` | целочисленное деление            |
|      `%` | остаток от деления               |
|      `-` | вычитание, унарный минус         |
|      `+` | сложение, конкатенация строк     |
|     `&&` | логическое И                     |
|   `\|\|` | логическое ИЛИ                   |
|      `!` | логическое НЕ                    |

## 6. Прочие лексемы

| Лексема | Предназначение                                                   |
| ------: | ---------------------------------------------------------------- |
|     `;` | Разделитель команд — завершает оператор                          |
|     `,` | Разделитель параметров в функциях и аргументах вызовов           |
|     `:` | Разделитель между именем и типом в объявлениях, для указания возвращаемого значения  |
|     `()` | Для записи условия и параметров функций           |
|     `{}` | Начало блока кода (функции, цикла, ветвления)                    |
|     `"` | Ограничитель однострочного строкового литерала                   |

## 7. Комментарии

Поддерживается два вида комментариев:

* **Однострочные комментарии** — `# текст однострочного комментария`

* **Многострочные комментарии** — `/* текст комментария, может содержать переносы строк */`
